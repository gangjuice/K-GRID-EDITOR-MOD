# K-GRID-EDITOR-MOD

배전 계통도(단선도) JPG를 인식해서 자체 편집 포맷으로 변환하고, 캔버스 기반으로 편집할 수 있는 도구 프로토타입입니다.

ADMS 계통관리시스템에서 출력된 JPG 단선도만 접근 가능한 환경을 전제로, 이미지 인식(심볼 탐지 + OCR) → 구조화된 JSON 변환 → 편집기(사람 검수) 흐름으로 설계했습니다.

## 구조

```
editor/     캔버스 기반 편집기 프로토타입 (React, Artifact로 실행 가능)
pipeline/   JPG → JSON 변환 파이프라인 프로토타입 (Python)
schema/     자체 JSON 포맷 예시
docs/       설계 노트
```

## 파이프라인 (pipeline/)

**한 번에 실행 (권장)**

```bash
pip install -r pipeline/requirements.txt
# Tesseract 본체 + 한글 학습데이터(kor.traineddata)가 시스템에 설치되어 있어야 합니다.

python3 pipeline/run_pipeline.py <입력.png> [출력폴더]
# 예: python3 pipeline/run_pipeline.py 250415_동평택_덕풍.png ./out
```

PNG 한 장을 넣으면 출력 폴더에 다음이 생성됩니다.

```
01_symbols_raw.json      단계1: 색상 기반 심볼 위치 탐지 결과
02_symbols_ocr.json      단계2: 심볼별 텍스트 OCR + 구조화 파싱 결과
03_editor_import.json    단계3: 편집기가 바로 읽을 수 있는 최종 JSON  ← 이 파일을 편집기에서 "불러오기"
```

세 단계를 하나로 합친 스크립트가 `run_pipeline.py`이고, 각 단계를 따로 돌려보며
디버깅하고 싶을 때는 아래 개별 스크립트를 순서대로 실행해도 동일한 결과가 나옵니다
(로직은 완전히 동일하며, `run_pipeline.py`가 이 셋을 그대로 내장한 버전입니다).

1. `01_symbol_detect.py` — 색상 기반(빨강/초록) 커넥티드 컴포넌트 분석으로 개폐기·S/L쌍 등 심볼 위치를 탐지합니다.
2. `02_ocr_extract.py` — 각 심볼 주변 텍스트 영역을 동적으로 크롭해 Tesseract(kor+eng)로 OCR 후, 정규식 기반으로 device_id / 케이블 규격 / 거리 필드를 구조화합니다.
3. `03_convert_to_editor_format.py` — 2번 결과를 편집기 JSON 스키마로 변환합니다.

**현재 상태(프로토타입 검증 결과)**
- 심볼 위치 탐지: 신뢰도 높음
- 텍스트 OCR: 1차 패턴 인식률 약 77%, 구조화 필드 파싱 성공률 약 56% (샘플 179개 노드 기준)
- 남은 이슈: 폰트 특성상 `S`/`8`, `T`/`1` 등 문자 혼동, 노드 타입별 라벨 위치 불균일 (수용가명은 심볼 옆, 나머지는 아래)

→ 완전 자동화 대신, "초안 자동 생성 + 편집기에서 사람이 빠르게 검수/수정"하는 반자동 워크플로우를 기본 전제로 합니다.

## 자체 JSON 포맷 (schema/)

```json
{
  "meta": { "title": "...", "source": "ADMS", "date": "..." },
  "nodes": [
    { "id": "고덕S2203", "type": "switch", "state": [1,0,1,0], "specs": ["CNCV(325)"], "distance_km": 0.1, "position": {"x":0,"y":0} }
  ],
  "edges": [
    { "id": "e1", "from": "A", "to": "B", "cable": "CNCV(325)", "distance_km": 0.1, "style": "solid" }
  ]
}
```

노드 타입: `source`(전원/CB) · `switch`(개폐기) · `pair_sl`(S/L쌍) · `transformer`(변압기) · `customer`(수용가)

## 편집기 (editor/)

`gyetongdo-editor.jsx` — React + SVG 기반 캔버스 에디터.

- 노드 클릭 → 우측 패널에서 ID/접점상태/케이블규격/거리 편집
- 노드 추가, 드래그 이동, 선로 연결(클릭 2회)
- JSON 불러오기 / 내보내기
- 원본 ADMS 도면 시각 언어 유지 (개폐기: 4점 다이아몬드 원, 변압기: 보라 격자, 수용가: 초록 격자, 케이블: 청록 선)

Claude.ai Artifact 환경에서 바로 렌더링해서 사용할 수 있고, 별도 React 프로젝트에 그대로 이식도 가능합니다.

## 컨버터 (pipeline/03_convert_to_editor_format.py)

`02_ocr_extract.py`의 출력(`symbols_final.json`)을 편집기가 바로 불러올 수 있는
JSON(`schema/example_auto_converted.json`)으로 변환합니다.

**현재 한계 (정직하게 기록)**
- 색상 마스크가 빨강/초록 원(개폐기, S/L쌍)만 잡기 때문에 변압기·수용가 아이콘은
  이번 변환에 포함되지 않습니다.
- 개폐기/S·L쌍 자동 구분 로직이 아직 실제 데이터에 잘 안 맞아서(179개 전부 switch로
  분류됨), 타입 분류 정확도가 낮습니다. → 이를 보완하기 위해 편집기에 **노드 타입
  변경 드롭다운**을 추가해서, 잘못 분류된 노드를 삭제 없이 바로 고칠 수 있게 했습니다.
- 접점 상태(1~4번 단자 on/off)는 심볼 전체 픽셀만 집계되어 있어 정확한 매핑 근거가
  부족합니다. 기본값으로 채우고 `needs_review: true`로 표시하며, 편집기에서 해당
  노드는 주황 테두리로 강조되고 좌측 패널에 검수 필요 개수가 표시됩니다.
- 선(엣지)/단자 연결은 자동 추출되지 않습니다. 노드만 채워지고, 연결은 편집기의
  "단자 연결" 모드로 직접 이어야 합니다.

즉 지금은 "빈 캔버스에서 직접 그리기"보다 조금 나은 정도(ID/규격/거리/대략적 위치는
자동으로 채워짐)이며, 타입 분류 정확도 개선이 다음 우선순위입니다.
