# K-GRID-EDITOR-MOD

배전 계통도(단선도) JPG를 인식해서 자체 편집 포맷으로 변환하고, 캔버스 기반으로 편집할 수 있는 도구 프로토타입입니다.

ADMS 계통관리시스템에서 출력된 JPG 단선도만 접근 가능한 환경을 전제로, 이미지 인식(심볼 탐지 + OCR) → 구조화된 JSON 변환 → 편집기(사람 검수) 흐름으로 설계했습니다.

## 구조

```
editor/     캔버스 기반 편집기 프로토타입 (React, Artifact로 실행 가능)
pipeline/   JPG → JSON 변환 파이프라인 프로토타입 (Python)
schema/     자체 JSON 포맷 예시
docs/       설계 노트
```

## 파이프라인 (pipeline/)

1. `01_symbol_detect.py` — 색상 기반(빨강/초록) 커넥티드 컴포넌트 분석으로 개폐기·변압기 등 심볼 위치를 탐지합니다. 별도 학습 없이도 ADMS 표준 출력물에서는 높은 정확도를 보였습니다.
2. `02_ocr_extract.py` — 각 심볼 주변 텍스트 영역을 동적으로 크롭해 Tesseract(kor+eng)로 OCR 후, 정규식 기반으로 device_id / 케이블 규격 / 거리 필드를 구조화합니다.

**현재 상태(프로토타입 검증 결과)**
- 심볼 위치 탐지: 신뢰도 높음
- 텍스트 OCR: 1차 패턴 인식률 약 77%, 구조화 필드 파싱 성공률 약 56% (샘플 179개 노드 기준)
- 남은 이슈: 폰트 특성상 `S`/`8`, `T`/`1` 등 문자 혼동, 노드 타입별 라벨 위치 불균일 (수용가명은 심볼 옆, 나머지는 아래)

→ 완전 자동화 대신, "초안 자동 생성 + 편집기에서 사람이 빠르게 검수/수정"하는 반자동 워크플로우를 기본 전제로 합니다.

## 자체 JSON 포맷 (schema/)

```json
{
  "meta": { "title": "...", "source": "ADMS", "date": "..." },
  "nodes": [
    { "id": "고덕S2203", "type": "switch", "state": [1,0,1,0], "specs": ["CNCV(325)"], "distance_km": 0.1, "position": {"x":0,"y":0} }
  ],
  "edges": [
    { "id": "e1", "from": "A", "to": "B", "cable": "CNCV(325)", "distance_km": 0.1, "style": "solid" }
  ]
}
```

노드 타입: `source`(전원/CB) · `switch`(개폐기) · `pair_sl`(S/L쌍) · `transformer`(변압기) · `customer`(수용가)

## 편집기 (editor/)

`gyetongdo-editor.jsx` — React + SVG 기반 캔버스 에디터.

- 노드 클릭 → 우측 패널에서 ID/접점상태/케이블규격/거리 편집
- 노드 추가, 드래그 이동, 선로 연결(클릭 2회)
- JSON 불러오기 / 내보내기
- 원본 ADMS 도면 시각 언어 유지 (개폐기: 4점 다이아몬드 원, 변압기: 보라 격자, 수용가: 초록 격자, 케이블: 청록 선)

Claude.ai Artifact 환경에서 바로 렌더링해서 사용할 수 있고, 별도 React 프로젝트에 그대로 이식도 가능합니다.
